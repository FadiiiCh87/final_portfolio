MUHAMMAD FAHAD — COMPLETE INTERACTIVE 3D PORTFOLIO

Is package mein HTML, CSS, JavaScript, original aur optimized photos,
project screenshots, resume PDF, font aur local Three.js 3D library shamil hain.
Website chalane ke liye npm install ya build ki zaroorat nahi.

XAMPP PAR CHALANE KA TAREEQA
1. ZIP extract karein.
2. Muhammad_Fahad_3D_Portfolio folder ko C:\xampp\htdocs mein copy karein.
   Agar XAMPP kisi aur drive mein hai to uske htdocs folder ko use karein.
3. XAMPP Control Panel mein Apache Start karein.
4. Browser mein ye URL kholein:
   http://localhost/Muhammad_Fahad_3D_Portfolio/
5. MySQL start karna zaroori nahi, kyun ke ye static portfolio hai.

PYTHON KE SAATH CHALANA
Windows par START_LOCAL_WINDOWS.bat ko double-click karein, phir kholein:
http://localhost:8000
Ya isi folder mein terminal khol kar command chalayein:
python -m http.server 8000 --bind 127.0.0.1
Server band karne ke liye terminal mein Ctrl+C dabayein.

ZAROORI BAAT
index.html ko seedha double-click karne ke bajaye localhost URL use karein.
JavaScript modules aur 3D scene HTTP server par sahi load hote hain.
Local assets internet ke baghair load ho sakte hain; GitHub, LinkedIn aur
email links ke liye unki relevant app/service ki zaroorat ho sakti hai.

FEATURES
- Real Three.js WebGL 3D explorer: drag, arrow keys aur clickable nodes.
- Flat view, pause/resume motion aur reduced-motion support.
- Project filters aur project overview dialogs.
- Skills tabs aur responsive mobile navigation.
- Resume download, original photos, contacts aur social links.
- Contact form email app mein draft kholta hai; visitor review karke send karta hai.
